# hr-policy-qa — Pigeonpost Nest reference app

A small first-party Nest app that answers HR policy questions from a bundled, synthetic handbook, using only the model broker. It is the reference release for the Pigeonpost Nests marketplace build plane (source: `deploy/nests/reference/hr-policy-qa` in bekirdag/pigeonpost). See https://developers.pigeonpost.dev/nests.html
